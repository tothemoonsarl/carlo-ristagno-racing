# Carlo Ristagno Racing

Site vitrine du pilote de karting Carlo Ristagno (#115 / #477, S125 Junior).
Site statique — déployé automatiquement sur Netlify à chaque push.

## Structure
- `index.html` — page unique (hero, pilote, résultats, agenda, galerie, partenaires, contact)
- `styles.css` / `script.js`
- `assets/` — logo, photos galerie, logos partenaires

## Mise à jour
Les modifications sont poussées ici, Netlify redéploie automatiquement.
